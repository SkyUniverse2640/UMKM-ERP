Bot & Developer Integration Guide

Connect automated bots, Point-of-Sale hardware, cron syncs, and accounting scripts directly with the UMKM Enterprise backend. Typed JSON, key-based auth, predictable errors.

Base URL: https://umkm.skyuniverse.tech Format: JSON

Authentication Protocol

Base URL: https://umkm.skyuniverse.tech

Every request must provide an active API Key via the Authorization or X-API-Key header. Keys are generated on the System page.

Authorization: Bearer <YOUR_API_KEY>

1. Daily Operations & Periodic Inventory

GET/api/daily-sales?date=YYYY-MM-DD
Query daily stock levels by date

Returns all SKU entries, starting stock, restock amounts, leftover quantities, calculated units sold, and recognized revenue.

curl -s -H "Authorization: Bearer <API_KEY>" \
  https://umkm.skyuniverse.tech/api/daily-sales?date=2026-09-25
import requests
res = requests.get("https://umkm.skyuniverse.tech/api/daily-sales",
    params={"date": "2026-09-25"},
    headers={"Authorization": "Bearer <API_KEY>"})
print(res.json())
const res = await fetch(
  "https://umkm.skyuniverse.tech/api/daily-sales?date=2026-09-25",
  { headers: { Authorization: "Bearer <API_KEY>" } });
console.log(await res.json());
POST/api/daily-sales
Submit Daily Inventory Count

Net sold = (starting + restock) - leftover.

curl -X POST https://umkm.skyuniverse.tech/api/daily-sales \
  -H "Authorization: Bearer <API_KEY>" -H "Content-Type: application/json" \
  -d '{"entry_date":"2026-09-25","item_id":1,"buyer_name":"Warung Berkah","starting_stock":25,"restock_quantity":10,"waste_quantity":2}'
import requests
res = requests.post("https://umkm.skyuniverse.tech/api/daily-sales",
    json={"entry_date":"2026-09-25","item_id":1,"buyer_name":"Warung Berkah",
          "starting_stock":25,"restock_quantity":10,"waste_quantity":2},
    headers={"Authorization":"Bearer <API_KEY>","Content-Type":"application/json"})
print(res.json())
const res = await fetch("https://umkm.skyuniverse.tech/api/daily-sales", {
  method: "POST",
  headers: { Authorization: "Bearer <API_KEY>", "Content-Type": "application/json" },
  body: JSON.stringify({entry_date:"2026-09-25",item_id:1,buyer_name:"Warung Berkah",starting_stock:25,restock_quantity:10,waste_quantity:2})
});
console.log(await res.json());
